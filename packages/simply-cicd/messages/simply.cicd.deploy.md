# flags.alias.summary

Salesforce org alias.

# flags.jwt-key-file.summary

Path to the JWT private key file.

# flags.debug.summary

Enable verbose debug logging.

# flags.vcs-host.summary

The source-control host to talk to (e.g. gitlab.com).

# flags.vcs-provider.summary

The source-control-hosting platform to talk to.

# flags.test-level.summary

The Apex test level to run.

# flags.test-suite.summary

The Apex test suite to run. If specified, overrides --test-level.

# flags.tests.summary

Specific Apex tests to run.

# flags.start-from.summary

Start (or resume) the deployment from a specific job name, overriding the progress file.

# flags.deploy-progress-file.summary

Path to the deployment progress file.

# flags.deploy-rules-file.summary

Path to the deployment rules file.

# flags.ci-job-token.summary

The CI job token used to authenticate read-only repository clones.

# flags.project-deploy-config-file.summary

Path to the deployment configuration file.

# flags.happy-soup-deploy-config-file.summary

Path to the deployment configuration file. If not provided, derived from --source-branch-name.

# flags.source-branch-name.summary

The source branch name for the deployment, used to derive the deployment config file path if --deploy-config-file is not provided.
