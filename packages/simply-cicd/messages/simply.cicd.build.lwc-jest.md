# summary

Install the LWC Jest test libraries and run the project's LWC Jest tests with coverage.

# description

Installs `@salesforce/sfdx-lwc-jest` and `@sa11y/jest`, then runs `sfdx-lwc-jest --coverage -- --passWithNoTests`. Failures are logged, not thrown.
